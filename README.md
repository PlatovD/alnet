# ALNet - Backend чат-приложения на Spring Boot

## ✨ Особенности
- **🔐 Безопасность** - JWT токены (access + refresh) с Spring Security, ролевая модель доступа
- **💬 Полноценные чаты** - Создание, редактирование, удаление чатов с управлением участниками
- **📡 Real-time коммуникация** - WebSocket для мгновенной доставки сообщений
- **👥 Управление доступом** - Проверка членства в чатах и авторства сообщений
- **📊 Пагинация** - Постраничная загрузка истории сообщений
- **🎯 Точечные обновления** - Поддержка JSON Patch для частичного обновления данных
- **🔧 Модульная архитектура** - Чистые слои, атомарные сервисы, фасады для сложной логики

## 🛠 Технологии
- **Backend**: Java 17, Spring Boot 3.1+, Spring MVC
- **Frontend**: Typescript, Vue
- **Безопасность**: Spring Security 6, JWT (jjwt 0.12+)
- **База данных**: Spring Data JPA, Hibernate, PostgreSQL (поддерживает любую SQL БД)
- **Real-time**: WebSocket, STOMP протокол, SockJS
- **Документация**: SpringDoc OpenAPI 3, Swagger UI
- **Инструменты**: Lombok, Maven, JSON Patch (json-patch)
- **Валидация**: Bean Validation (Jakarta), кастомные исключения

## 📡 API Endpoints

### 🔐 Аутентификация (`/auth/*`)
| Метод | Endpoint | Описание | Auth |
|-------|----------|----------|------|
| `POST` | `/auth/sign-up` | Регистрация нового пользователя | ❌ |
| `POST` | `/auth/sign-in` | Вход, получение JWT токенов | ❌ |
| `POST` | `/auth/refresh` | Обновление access токена | ❌ |

### 👥 Пользователи (`/api/users/*`)
| Метод | Endpoint | Описание | Auth | Ограничения |
|-------|----------|----------|------|------------|
| `GET` | `/api/users/{userId}` | Получить информацию о пользователе | ✅ | - |
| `PUT` | `/api/users/{userId}` | Полное обновление данных | ✅ | Только свой профиль |
| `PATCH` | `/api/users/{userId}` | Частичное обновление (JSON Patch) | ✅ | Только свой профиль |
| `DELETE` | `/api/users/{userId}` | Удаление пользователя | ✅ | Только свой профиль |

### 💬 Чаты (`/api/chats/*`)
| Метод | Endpoint | Описание | Auth | Ограничения |
|-------|----------|----------|------|------------|
| `GET` | `/api/chats/{chatId}` | Получить информацию о чате | ✅ | Только участник чата |
| `POST` | `/api/chats` | Создать новый чат | ✅ | - |
| `PUT` | `/api/chats/{chatId}` | Обновить информацию о чате | ✅ | Только участник чата |
| `DELETE` | `/api/chats/{chatId}` | Удалить чат | ✅ | Только участник чата |

### 📨 Сообщения (`/api/message/*`)
| Метод | Endpoint | Описание | Auth | Ограничения | Параметры |
|-------|----------|----------|------|------------|----------|
| `GET` | `/api/message/{chatId}` | История сообщений чата | ✅ | Только участник | `page`, `size`, `sort` |
| `PUT` | `/api/message/{messageId}` | Редактировать сообщение | ✅ | Только автор | - |
| `DELETE` | `/api/message/{messageId}` | Удалить сообщение | ✅ | Только автор | - |

### 👥 Управление участниками (`/api/membership/*`)
| Метод | Endpoint | Описание | Auth | Ограничения |
|-------|----------|----------|------|------------|
| `GET` | `/api/membership` | Список чатов текущего пользователя | ✅ | - |
| `GET` | `/api/membership/{chatId}` | Все участники чата | ✅ | Только участник чата |
| `POST` | `/api/membership/{chatId}` | Добавить пользователей в чат | ✅ | Только участник чата |
| `DELETE` | `/api/membership/{chatId}` | Удалить пользователей из чата | ✅ | Только участник чата |

### 🔌 WebSocket (`/ws`)
| Тип | Endpoint | Описание | Аутентификация |
|-----|----------|----------|----------------|
| `WS` | `/ws` | WebSocket endpoint для подключения | JWT в заголовке |
| `STOMP` | `/app/chats/{chatId}` | Отправка сообщений в чат | Требуется членство |
| `STOMP` | `/topic/chats/{chatId}` | Подписка на сообщения чата | Требуется членство |

## 🔐 Security Matrix
| Endpoint Pattern | Доступ | Требования |
|------------------|--------|------------|
| `/auth/**` | ✅ Публичный | - |
| `/ws/**` | ✅ Публичный | Аутентификация через JWT в WebSocket |
| `/swagger-ui/**`, `/v3/api-docs/**` | ✅ Публичный | - |
| `/error` | ✅ Публичный | - |
| `/admin/**` | ❌ Приватный | Только роль `ADMIN` |
| `/api/**` | ❌ Приватный | Любой аутентифицированный пользователь |
| `/api/users/{userId}` | ❌ Приватный | Свой userId или доступ по ролям |

## 🚦 HTTP Status Codes
- `200 OK` - Успешный GET, PUT, PATCH
- `201 Created` - Успешный POST (ресурс создан)
- `204 No Content` - Успешный DELETE
- `400 Bad Request` - Неверные данные запроса
- `401 Unauthorized` - Не авторизован (нет/неверный JWT)
- `403 Forbidden` - Нет прав на операцию
- `404 Not Found` - Ресурс не существует
- `409 Conflict` - Конфликт данных (повторяющийся username/email)
- `422 Unprocessable Entity` - Ошибка валидации или JSON Patch
